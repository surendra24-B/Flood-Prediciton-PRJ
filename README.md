# 🌊 Flood Prediction.AI

An AI-powered web application that predicts the likelihood of flooding using weather and rainfall parameters. This project combines **Machine Learning** with a modern **Flask-based web interface** to provide quick and interactive flood risk predictions.

---

## 📌 Project Overview

Flood Prediction.AI is designed to assist in estimating flood risk based on environmental and rainfall-related factors. The application uses a trained Machine Learning model to analyze user-provided inputs and predict whether flood conditions are likely.

The web application provides:

- 🌊 Flood Risk Prediction
- 📊 Prediction Confidence Score
- ⚠️ Risk-Based Safety Recommendations
- 🎨 Modern AI-Themed User Interface
- 📱 Fully Responsive Design

## 📊 Input Parameters

The model predicts flood risk using the following six features:

| Feature | Description |
|----------|-------------|
| Temperature | Temperature (°C) |
| Humidity | Relative Humidity (%) |
| Annual Rainfall | Total Annual Rainfall |
| Jun-Sep Rainfall | Rainfall during June–September |
| Average June Rainfall | Average Rainfall in June |
| Subdivision Index | Region/Subdivision Identifier |
